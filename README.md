# No Dropped Items
No Dropped Items is a simple and lightweight server-side mod that, when enabled automatically removes all dropped items from the game. It has multiple uses, including getting rid of the mess left over by harvesting mods, preventing droppers from being used, allowing for easy discarding of unwanted items, and reducing the overall in-game entity count.

## Usage
To enable/disable simply use the command `/ndi` (Short for "No Dropped Items"). This will toggle if it should get rid of all dropped items or not.
When enabled, the mod will remove all the dropped items, whether they came from a player, mob, or object each tick. If you decide that you want to be able to drop items again, simply disable the mod with the same command `/ndi`.
